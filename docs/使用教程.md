### 2.1 先去拿一个 API Key（以 DeepSeek 为例，最便宜）

1. 打开 <https://platform.deepseek.com/>，注册/登录
2. 左侧「API keys」→ 创建 API Key → 复制保存（只显示一次）

> 也可以用 OpenAI、通义千问、Kimi、硅基流动等，只要兼容 OpenAI 接口都行。

### 2.2 填进 AstrBot

1. 浏览器打开 <http://127.0.0.1:6185>，用 `astrbot / change-me-panel` 登录
2. 左侧菜单 **「服务提供商」**（Provider）
3. 点 **「新增」/「添加服务提供商」**
4. 按下面填（类型选 OpenAI 兼容 / OpenAI）：

| 字段 | 值（DeepSeek） |
|---|---|
| 类型 | OpenAI / OpenAI 兼容 |
| 名称 | `deepseek`（随便起） |
| API Base URL | `https://api.deepseek.com/v1` |
| API Key | 你刚复制的那串 |
| 模型 | `deepseek-chat`（便宜）或 `deepseek-reasoner`（更聪明更贵） |

5. 保存后，在列表里把这条**设为默认 / 启用**
6. 页面提示配置生效即可

### 2.3 验证

用**另一个 QQ 号**（或让朋友）私聊「大肥鱼」，发一句 `你好`。
10 秒内收到回复 = 成功。

如果没回复：
- 看 AstrBot 面板 →「数据与日志」→ 有没有报错（API Key 错、余额不足最常见）
- 看本教程第 8 节

## 8. 出问题怎么办（按这个顺序查）

> **自动机制总览（重要）**
>
> | 机制 | 频率 | 作用 |
> |---|---|---|
> | `io-watchdog.timer` v2 | 30 秒 | I/O 压力 >80% 或内存 >60% 连续 150 秒才停 QQ；**QQ 启动后 10 分钟内不判定**（登录同步期保护） |
> | `snowluma-guard.timer` | 2 分钟 | 发现 QQ 容器没在跑、且资源健康（MemAvailable>180MB、io<40%）→ **自动 `docker start snowluma`** |
> | `qq-health.timer` | 5 分钟 | **QQ 掉线连续 2 次 → 自动 `docker restart snowluma`**（30 分钟冷却） |
>
> ⚠️ **前提：QQ 客户端必须勾选「自动登录」**（noVNC 登录界面左下角）。
> 勾了以后客户端重启会自动登回；不勾就会停在扫码界面等人——2026-11-12 离线 32 小时就是这个原因。
> 日志：`/var/log/io-watchdog.log`、`/var/log/snowluma-guard.log`、`/var/log/qq-health.log`

| 现象 | 原因 | 解决 |
|---|---|---|
| 面板打不开 | 隧道没开/断了 | 双击 `启动隧道.bat`；先试 <http://127.0.0.1:6185> |
| noVNC 里二维码"已过期" | QQ 二维码只有 ~60 秒 | 点二维码区域的「刷新」，**立刻**扫 |
| 改了设置没生效 | 需要重启对应容器 | 告诉我"重启一下 astrbot" |
| 机器人收到消息不回 | 没配 LLM / Key 错 / 余额不足 | 第 2 节 + 看日志 |
| QQ 掉线（面板里显示未连接） | 需要重新扫码 | 开 noVNC 扫码；之后务必勾「自动登录」 |
| 服务器很卡 / SSH 连不上 | 内存或 I/O 压力（1.6G 内存硬限制） | 看门狗会自动停 QQ 容器保命；告诉我，我恢复并调参 |

> 看门狗已装好：I/O 或内存压力持续超标时，它会**自动只停 QQ 容器**（机器人掉线但服务器不会死），
> 你 SSH 进来重启容器即可恢复。

## 14. 表情包：模型自主发送（2026-10-29 已上线）

**不再是关键词规则，也不是随机** —— 让模型自己判断什么时候该发哪张。

### 原理

1. 插件把 **70 张表情包的名字**（`01_不服气`、`17_摆烂当废物`、`18_晚安`…）注入系统提示词，告诉模型"名字即含义"
2. 模型觉得该发时，在回复最后写一行 `[[表情:名字]]`
3. 插件去掉标记、替换成真实图片发出（每条最多 1 张，可配置）

### 实测效果

| 你说 | 它自己发的 |
|---|---|
| 困死了想睡觉 | `07_困了.gif` |
| 谢谢你帮我 | `18_晚安.gif` |
| 这破班我真是一天不想上了 | `17_摆烂当废物.JPG` |
| 我今天被夸了，好开心 | `02_开心.gif` |
| 在吗 | `19_在吗.gif` |

### 怎么调整

控制台 →「表情包」卡片：

- **发表情方式**：`模型自主判断`（默认）/ `关键词规则` / `不发表情`
- **每条最多**：默认 1 张，可调 1–3
- 文件名就是语义，改名/新增后**自动生效**（无需重启 AstrBot）

### 注意

- 名字以 `_` 开头的文件（如 `_预览总览.png`）不算表情包
- 模型偶尔选得不完美（比如道谢时发了「晚安」），属正常
- 觉得发得太频繁/太少，告诉我，我调整提示词里的频率要求

## 15. QQ Cookie / QQ 空间集成（2026-10-29 已接通）

### 能力确认

SnowLuma 的 OneBot 接口**支持**取 Cookie（实测）：

```json
GET /get_cookies?domain=qzone.qq.com
-> {"status":"ok","data":{"cookies":"pt2gguin=...; uin=...; skey=@B2d9nT8y3; p_skey=...; p_uin=..."}}
GET /get_csrf_token   -> {"data":{"token":65944124}}
GET /get_credentials  -> 返回 cookies
```

返回的 Cookie 含 `uin / p_uin / skey / p_skey`，正是 QQ 空间类操作需要的字段。

### 控制台取 Cookie

控制台首页新增 **「QQ Cookie」** 卡片：
- 点「获取最新」→ 显示 csrf_token 和完整 Cookie
- 点「复制 Cookie」→ 粘贴到需要的地方
- Cookie 会过期，用前重新取

### 自动给"空间"功能喂 Cookie（已配好，不用管）

private_companion 的 QQ 空间功能需要 `QZONE_COOKIE`，已做成**自动刷新**：

| 项目 | 说明 |
|---|---|
| 脚本 | `/opt/qqbot/scripts/refresh-qzone-cookie.sh` |
| 定时器 | `qzone-cookie.timer`，**开机 3 分钟后 + 每 6 小时** |
| 动作 | 从 SnowLuma 取最新 Cookie → 写入插件配置 → **热重载插件**（不重启 AstrBot） |
| 日志 | `/var/log/qzone-cookie.log` |

手动立即刷新：

```bash
bash /opt/qqbot/scripts/refresh-qzone-cookie.sh
```

> 实测：用这份 Cookie 访问 QQ 空间返回 HTTP 200（不是登录跳转页）。

### 如果你说的是别的功能

Cookie 也可以给其他插件用（如 `astrbot_plugin_qzone`）。告诉我具体是哪个插件/功能，我把 Cookie 对接过去。
