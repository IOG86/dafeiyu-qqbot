# 大肥鱼控制台 · 使用说明

> 控制台装在**你自己的电脑**上，只监听 `127.0.0.1:8090`，不对外暴露。
> 它通过 SSH 操作服务器，通过 SSH 隧道访问 AstrBot 面板。

## 一、启动

1. 先双击 `deploy\启动隧道.bat`（保持黑窗口别关）
2. 再双击 `console\启动控制台.bat` → 浏览器自动打开 <http://127.0.0.1:8090>
3. 关闭控制台窗口即停止

> 直接在 `console` 目录执行 `py -3 -u app.py` 也可以。

## 二、界面功能

| 区块 | 说明 |
|---|---|
| **运行状态** | QQ 在线/账号、容器状态、内存、I/O 压力、磁盘、运行时长、已加载插件、**识图（视觉模型）是否配置**；一键重启 AstrBot / QQ / 全部 |
| **DeepSeek 余额** | 实时查余额，< 5 元变红。DeepSeek 没有历史用量 API，用量看官网账单 |
| **表情包** | 上传（多选）/删除、总开关、「随机发表情」概率滑杆 |
| **关键词 → 表情** | 用户消息包含关键词 → 机器人回复后附上指定表情；保存后即时生效。底部有**规则测试**：输入一句话预演会命中哪条（不会真发消息） |
| **聊天测试** | 直接与机器人对话（webchat 通道，不占用 QQ，需要隧道） |
| **AstrBot 日志** | 最近 120 行 |

## 三、表情包工作原理

- 图片存放：服务器 `/opt/qqbot/astrbot/data/dafeiyu_console/stickers/`
- 规则文件：服务器 `/opt/qqbot/astrbot/data/dafeiyu_console/rules.json`
- 执行插件：`astrbot_plugin_dafeiyu_sticker`（自研，已装并加载）
- 逻辑：
  1. 用户消息命中关键词 → 在机器人这条回复后追加对应表情（文字 + 图一起发）
  2. 未命中时，按「随机概率」追加一张随机表情
- 改规则/传表情**即时生效**，不用重启 AstrBot

规则文件结构：

```json
{
  "enabled": true,
  "random_probability": 0.15,
  "rules": [
    { "keyword": "夸我", "sticker": "示例-陪伴.png" }
  ]
}
```

## 四、关于"看懂表情包"

当前模型是 **DeepSeek `deepseek-chat`**，**不支持看图**，所以机器人暂时看不懂别人发的表情包。

要支持，需要加一个**视觉模型**（推荐智谱 `GLM-4V-Flash`，有免费额度）：

1. 到 <https://open.bigmodel.cn/> 注册，创建 API Key
2. AstrBot 面板 →「服务提供商」→ 新增（智谱 / OpenAI 兼容），模型填视觉模型
3. 修改 AstrBot 配置 `provider_settings.default_image_caption_provider_id` = 该 Provider 的 id
4. private_companion 配置里 `PLUGIN_VISION_PROVIDER_ID` 同样指向它

配好后：别人发图 → AstrBot 先把图转成文字描述 → 再交给大模型 → 它就能"看懂"并回应。

## 五、常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 控制台打不开 | 没运行 `启动控制台.bat`；或 Python 不是 `py -3` |
| 状态显示"连不上服务器" | 服务器 SSH 不通，或密钥文件被移动 |
| 余额显示"获取失败" | 服务器出网异常，或 Key 被撤销 |
| 聊天测试报错"隧道没开" | 先双击 `启动隧道.bat` |
| 表情包列表空白 | 服务器上还没有图片，先上传；或 scp 同步失败（点刷新重试） |
| 发了关键词但没表情 | 确认「启用」开着、规则已保存、用的是 QQ 私聊/群聊（webchat 不显示图片组件） |
